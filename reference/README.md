## 3. Retningslinjer for Nye Scener

For at en ny scene passer perfekt ind i piktogramkortet skal den overholde:
1. **Gennemsigtig baggrund:** 100% transparent PNG (figuren og rekvisitterne placeres oven på kortets baggrundsfarve).
2. **Karakterkonsistens:** Brug `personas/{id}/avatar.webp` som figurreference (Ref 1).
3. **Tegnestil:** Brug `style_guide/ref2_example.jpg` som tegnestilsreference (Ref 2) med tykke sorte cel-shading streger og klare mættede farver.
4. **Billedformat:** Vandret 16:9 komposition så figuren udfylder billedfeltet harmonisk.
